# TRUST-TC Notebook Examples

The notebook in this folder provides a step by step quickstart for the public
TRUST-TC interval analysis tool.

Launch it interactively from the repository root:

```powershell
jupyter notebook notebooks/trust_tc_interval_quickstart.ipynb
```

Execute it non-interactively:

```powershell
jupyter nbconvert --to notebook --execute notebooks/trust_tc_interval_quickstart.ipynb --output executed_quickstart.ipynb
```

Notebook outputs are generated locally under `outputs/tool_demo/`.
